Absorbance spectrum acquisition issues

The text accompanying the fields in the Acquisition and wavelength setup window blends in with the background and is impossible to see. Issue can be seen in Screenshot 2025-12-21 160009 in the debugScreenshots folder.

The two spectra graphs in the Capture Reference and Capture Dark windows should be placed vertically, not horizontally as they are now. For both windows, the first graph should show the spectrum being acquired in real time following the settings provided in the Acquisition and wavelength setup window. For both windows, the second graph (which is below the first one) should show the spectrum that was captured after pressing the Capture with current settings button.

The graph in the Results and overlays window should show the resultant absorbance spectrum in real time while respecting the settings values provided by the user in the Acquisition and wavelength setup window. There should not be a Capture sample for result button as the results must be updated in real time and plotted on the graph. The window with the current result is unnecessary and must be removed. Finally, the Finish button is inactive when it is supposed to update the main graph in Vis Spectroscopy to work in absorbance mode while respecting the settings values provided by the user in the Acquisition and wavelength setup window.
